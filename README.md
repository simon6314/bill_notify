# 帳單管理

記錄信用卡與定期繳費（房貸、水費、瓦斯費…），每月確認是否已繳納，下個月自動重新確認。

- 前端：GitHub Pages（`index.html`、`app.js`、`style.css`）
- 後端：Google 試算表 + Apps Script（`apps-script/Code.gs`）

## 設定步驟

1. **建立試算表**：到 Google 雲端硬碟新建一個試算表，名稱例如「帳單」。
2. **貼上後端程式**：在試算表中選「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 整段貼上取代原本內容，存檔。
3. **初始化工作表**：在 Apps Script 編輯器選 `ensureSheets` 執行一次（第一次會要求授權），試算表會多出「帳單設定」與「繳費紀錄」兩個分頁。
4. **部署網頁應用程式**：「部署 → 新增部署作業 → 網頁應用程式」，執行身分選「我」，存取權選「任何人」，部署後複製網址。
5. **填入網址**：把 `app.js` 最上面的 `API_URL` 改成剛剛複製的網址，存檔、推上 GitHub。
6. **開啟 GitHub Pages**：repo 的 Settings → Pages → Source 選 `main` 分支、`/ (root)`。

## 資料結構

- **帳單設定**：每一筆是一張信用卡或一項定期繳費（名稱、類型、結帳日、繳款日、扣款帳戶、自動扣繳、預設金額、備註）。
- **繳費紀錄**：以「月份 + 帳單」為一列，記錄該月金額與是否已繳。下個月沒有紀錄，就自動視為未繳，所以每月會重新確認。

## 注意

- Apps Script 網址等於存取權限，請不要公開分享。
- 修改 `Code.gs` 後要「管理部署作業 → 新版本」重新部署，網址不變。
